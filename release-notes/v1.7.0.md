# Clash Node Checker v1.7.0

## Highlights

- Added TLS dual probe modes:
  - Fast mode: lightweight ClientHello preflight.
  - Standard mode: rustls handshake path (connectivity-focused, cert verification disabled for probe compatibility).
- Added export filters for available-node export:
  - Protocol filter
  - Minimum security score
  - Maximum TCP average latency (`0` means unlimited)
- Added detection history snapshots:
  - Auto-save on each completed run
  - Stored at `dist/history/snapshots.json`
  - Keep latest 40 snapshots
  - Viewable from a dedicated history window in UI
- Expanded top menu actions:
  - Detection menu now includes TLS mode switching
  - View menu now includes history window entry

- Windows executable bundle (.zip)
- Standalone Windows executable (.exe)
