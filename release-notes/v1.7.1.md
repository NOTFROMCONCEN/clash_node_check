# Clash Node Checker v1.7.1

## Highlights

- Optimized local bulk import:
  - Limit directory scan depth to 8 levels.
  - Limit scanned files to 5000.
  - Skip candidate config files larger than 8MB.
  - Show skipped large files and scan limit hits in the import summary.
- Optimized available-node export:
  - Export results are sorted by security score descending, then TCP average latency ascending.
  - Added "best N nodes" export limit (`0` means unlimited).
- Optimized history snapshots:
  - Show readable UTC timestamps instead of raw Unix timestamps.
  - Show strict pass rate, fail rate, TCP alive rate, and trend versus the previous snapshot.
- Added tests for scan limits, history formatting, and trend summaries.

- Standalone Windows executable (.exe)
